# Polices auto-hébergées

Toutes sont sous licence SIL Open Font License 1.1 (textes joints).

| Fichier | Origine | Usage |
| --- | --- | --- |
| `lato-300/400/700.woff2` | Lato, sous-ensemble latin de Google Fonts | texte courant |
| `playfair-display-400-italic.woff2` | Playfair Display Italic, sous-ensemble latin de Google Fonts | citations, liens d'appel |
| `titres-web-400.woff2`, `titres-web-700.woff2` | instances statiques (graisses 400 et 700) de Playfair Display, police variable, sous-ensemble latin | titres |

Les deux fichiers `titres-web-*` sont des versions modifiées (instanciation de
l'axe de graisse) : conformément à la licence, qui réserve le nom
« Playfair Display », leur nom interne est « Titres Web ». La feuille de style
les déclare sous la famille CSS `'Playfair Display'`, avec l'italique d'origine.
